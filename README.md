# CareFlow: Clinical Pathway Process Mining

## Project Overview
CareFlow is a data analytics project aimed at analyzing clinical event logs, mapping patient journeys across healthcare pathways, and identifying operational bottlenecks to improve patient care throughput.

## Work Completed (Mid Review)
- **Week 1:** Data collection, event log structuring (Patient ID, Activity, Timestamp), and cleaning duplicates/missing records.
- **Week 2:** Exploratory Data Analysis (EDA), Patient Length of Stay (LOS) metrics calculation, and pathway variant extraction.

## Future Deliverables (Final Review)
- Interactive Dashboard (Power BI / Tableau)
- Process Flow Analysis & Bottleneck Identification
- End-to-End Project Report & Documentation
